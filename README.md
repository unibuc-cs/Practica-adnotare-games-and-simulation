## Submission Summary

Each student must submit:

- `annotations.jsonl` (at least 40 labeled moments)
- `clips/` folder containing `clips/<qid>.mp4`
- A ZIP file named:

  `YourFullName_<GAME>.zip`

Where `<GAME>` is one of:
- `GTA5`
- `BF6`
- `ACS`
